# 06. 개발 로드맵 (Claude Code 100% 개발)

> 각 마일스톤은 **"Claude Code 에게 한 번에 맡길 수 있는 크기"** 로 쪼갰다.
> 모든 마일스톤은 **완료 조건(DoD)** 을 자동 테스트로 확인할 수 있게 정의한다.
> 사람(개발사)이 직접 해야 하는 일은 🧑 로 표시 (계정·콘솔 설정, 실기기 확인 등).

---

## 전체 일정 (예상, 1인 + Claude Code 기준)

| 단계 | 마일스톤 | 기간 |
|---|---|---|
| 프로토타입 | M0 ~ M3 | 3~4주 |
| 알파(콘텐츠 완성) | M4 ~ M7.7 | 9~10주 |
| 베타(연동·보안·폴리싱) | M8 ~ M10 | 4주 |
| 출시 | M11 | 2주 (비공개 테스트 포함) |
| **합계** | | **약 18~20주** |

---

## M0. 프로젝트 기반
- Gradle 멀티모듈(`:engine`, `:game`, `:app`), Version Catalog, Compose 테마(디자인 토큰), ktlint/detekt, GitHub Actions CI.
- 🧑 Google Play 개발자 계정 등록($25), 패키지명 확정(예: `com.<회사>.chronoknight`).
- **DoD**: `./gradlew check assembleDebug` CI 통과, 빈 로비 화면 실행.

## M1. 엔진 코어
- 고정 틱 루프, Rng, SoA 엔티티 저장소, 풀, Spatial Hash, 카메라, 플로팅 조이스틱, 아틀라스 베이커, Canvas 렌더러.
- 기사 이동 + 기본 공격(장검), 적 2종(▲■), 경험치 결정.
- **DoD**: 적 250마리 스폰 벤치마크 테스트에서 틱당 < 4ms(JVM), 루프 내 할당 0, 결정성 테스트 통과.

## M2. 룬 시계 (핵심 재미 검증)
- 룬 24종, 반응 8종, 레벨업 3택1 UI, 드래그 배치, 자동 배치, 정오·공명·템포 규칙.
- **DoD**: 룬 시계 단위 테스트(발동 순서, 반응 판정, 정오 ×2, 공명), 반응 연출 동작. 🧑 실기기 플레이 테스트 → "재밌는가" 판단 (여기서 재미가 없으면 규칙 조정 후 진행).

## M3. 스테이지 한 판 완성
- 10웨이브, 적 6종, 미니보스·보스 3종, 부활, 결과 화면, 튜토리얼 스테이지(FTUE 1~3분).
- **DoD**: 헤드리스 시뮬레이터로 1-1 ~ 1-10 클리어율 리포트 생성.

## M4. 메타 성장
- SaveGame 모델, 로컬 암호화 저장, 계정 레벨, 훈련, 장비 6부위·합성·강화, 룬 숙련, 로비 5탭.
- **DoD**: 세이브 저장/복원·마이그레이션·변조 탐지 테스트, 합성 규칙 테스트.

## M5. 콘텐츠 확장
- 챕터 1~10 데이터, 보스 10종, 일일 던전 2종, 무한의 탑, 야영지(오프라인 보상, 시간 조작 방지).
- **DoD**: 스테이지 1~100 시뮬레이션 클리어율이 목표 곡선(40~60%) 이내, 오프라인 보상 경계값 테스트.

## M6. 그림자 라이벌 · 거울의 시련
- 경로 기록/재생, 처치 수 비교 게이지, 추월 스택, 거울 기사 AI, 주간 초기화.
- **DoD**: 기록 → 재생 좌표 오차 테스트, 그림자 파일 용량 상한 테스트.

## M7. 리텐션 시스템
- 일일/주간 퀘스트, 출석 7/28일, 업적, 시즌 패스(무료/프리미엄 트랙), 로컬 알림(WorkManager), 빌드 공유 이미지(1080×1350)·빌드 코드, **하이라이트 릴스 MP4 생성**(오프스크린 재렌더링 + MediaCodec).
- **DoD**: 날짜 경계(자정·시간대 변경) 초기화 테스트, 같은 시드 재렌더링 결과가 원본 전투와 일치하는지 결정성 테스트.

## M7.5 수집·스킬 시스템 (08 문서)
- 오브 52종·룬 30종·펫 20종 데이터(JSON), 효과 레지스트리(`EffectRegistry`), 패시브 9·액티브 20, 태그 공명·각인 40종.
- **DoD**: 모든 아이템 효과 타입 단위 테스트, 태그 공명 3/5/7 단계 전환 테스트, 액티브 쿨다운·판 시작 50% 충전 테스트.

## M7.6 요일 던전 미니게임 · 스토리 (10 문서)
- `SideScrollMode`, `DuelMode`, `TacticsMode` (전투 코어 재사용), 스토리 뷰어(대사 JSON, 스킵·요약), 시대 1 대사 50스테이지.
- **DoD**: 각 모드 승리/패배 조건 테스트, 전술 퍼즐 30개 풀이 가능성 자동 검증(솔버), 대사 JSON 스키마 검증.

## M7.7 히든 · 유일 · 합성 (09 문서)
- 공개 합성, 히든 레시피(해시 매칭), 각성 조건 추적, 유일룬 지정 칸 장착 규칙, 숨은 시너지 12종.
- **DoD**: 히든 조건 달성 시뮬레이션 테스트, 레시피 해시 매칭 테스트, 유일룬 중복 소유 불가·소환 제외 테스트, 앱 번들 평문 유출 검사.

## M8. 수익화
- 소환(확률·10회 보장·천장·마일리지·픽업), 상점, Play Billing, AdMob 보상형 + UMP.
- 🧑 Play Console 인앱 상품 등록, AdMob 계정·광고 단위 생성, 라이선스 테스터 등록.
- **DoD**: 확률 100만 회 테스트, 천장 테스트, 가짜 BillingClient 로 성공/취소/PENDING/복구/중복 시나리오 테스트.

## M9. 구글 계정 연동 · 운영 도구
- PGS v2 로그인, 저장된 게임 동기화·충돌 해결 UI, 리더보드·업적, Firebase Remote Config/Analytics/Crashlytics.
- 🧑 Play Console 게임즈 서비스 설정(저장된 게임 ON, SHA-1 등록), Firebase 프로젝트 생성.
- **DoD**: 충돌 해결 정책 단위 테스트, 🧑 두 기기 간 세이브 이동 실기기 확인.

## M10. 보안 · 폴리싱 · 최적화
- R8, 무결성 검사, 메모리 값 난독화, 결제 서명 검증, 품질 옵션 자동 선택, 타격감 체크리스트, 사운드, 접근성, 영어 현지화.
- **DoD**: [05 문서 §11 체크리스트](05-security-compliance.md) 전 항목 통과, 🧑 저사양 실기기 30fps 확인.

## M11. 출시
- 🧑 스토어 등록정보(ASO), 개인정보처리방침·확률 공시 웹페이지, 데이터 보안 양식, IARC 등급.
- 🧑 **비공개 테스트**(신규 개인 개발자 계정은 Google Play 정책상 일정 인원·기간의 비공개 테스트 후 프로덕션 신청 가능 — 등록 시점 정책 확인) → 사전예약 → 출시.
- **DoD**: 프로덕션 출시, Crashlytics 비정상 종료 없는 사용자 비율 99.5% 이상.
