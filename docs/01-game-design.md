# 01. 게임 기획서 — CHRONO KNIGHT (가제)

> 문서 버전 1.0 · 대상: 개발(Claude Code), 기획, 아트, QA
> 가제는 출시 전 상표 검색(KIPRIS / Google Play 검색) 후 확정한다.

---

## 1. 기획 의도

### 1.1 시장 분석 — 최근 Google Play 상위권 캐주얼/미드코어의 공통점

| 성공 요인 | 대표 사례 유형 | 본 게임 적용 |
|---|---|---|
| 한 손·한 손가락 조작 | 서바이버류, 궁수류 로그라이트 | 드래그 이동만, 공격·스킬은 자동 |
| 3~5분의 짧은 세션 | 서바이버류 | 한 판 = 5분 (10웨이브 × 30초) |
| 매 판 달라지는 빌드 | 로그라이트 | 룬 3택 1 + **룬 시계 배치** |
| 끝없이 오르는 숫자 | 방치형 RPG | 훈련(무한 강화), 오프라인 보상 |
| 단일 캐릭터 몰입 | 슬라임/용사 방치형 | 기사 1명만 육성 |
| 가벼운 갓챠 | 캐주얼 로그라이트 | 장비 소환 + 합성, 천장·마일리지 |

**차별화 포인트**: 기존 서바이버류는 "스킬 선택"에서 빌드가 끝난다.
본 게임은 **"어디에 놓느냐"**(룬 시계 배치)라는 두 번째 축을 추가해,
같은 스킬 조합이라도 배치에 따라 결과가 달라지는 **가벼운 퍼즐의 쾌감**을 준다.
또한 **"어제의 나"와 겨루는 그림자 라이벌**로 서버 없이도 경쟁 욕구를 자극한다.

### 1.2 디자인 필러 (모든 결정의 기준)

1. **한 손, 한 판 5분** — 지하철 한 정거장 사이에도 한 판.
2. **배치가 곧 실력** — 룬 시계 배치로 빌드의 개성과 깊이를 만든다.
3. **항상 성장하고 있다는 감각** — 져도 무언가 오른다. 접속하지 않아도 오른다.
4. **나를 이긴다** — 경쟁 상대는 과거의 나.
5. **공정한 과금** — 갓챠는 "가속"이지 "필수"가 아니다. 확률 공개, 천장 보장.

### 1.3 타겟

- 1차: 10대 후반~30대, 출퇴근·자투리 시간 플레이어 (서바이버류/방치형 경험자)
- 2차: 퍼즐·빌드 연구를 좋아하는 미드코어 (공략 공유, 커뮤니티 형성층)
- 국가: 한국 우선 출시 → 일본·동남아·영어권 글로벌 (텍스트 분리 설계로 현지화 대비)

## 2. 세계관 (짧고 가볍게)

- 시간이 산산이 부서진 세계 **크로노스피어**. 부서진 시간의 틈에서 **글리치(Glitch)** —
  기하학 파편으로 이루어진 괴물들이 쏟아져 나온다.
- 주인공은 마지막 시계탑을 지키는 **시계탑의 기사**. 시계탑의 심장인 **룬 시계**를 갑옷에 품고,
  시간을 되감으며(= 재도전) 싸운다.
- **그림자 라이벌**은 되감기 때마다 남는 "이전 시간선의 나"의 잔상이다.
- 적이 기하학 도형 형태라는 설정은 **절차적(코드) 아트 제작**과 자연스럽게 맞물린다
  (→ 아트 리소스 부담 최소화, [03-design-ux.md](03-design-ux.md) 참고).

## 3. 코어 루프

```
            ┌──────────────────────────────────────────┐
            │                                          │
            ▼                                          │
  [로비] 기사 성장(훈련/장비/룬숙련)                     │
            │                                          │
            ▼                                          │
  [전투 5분] 이동·생존 → 경험치 → 룬 3택1 → 룬 시계 배치 │
            │                                          │
            ▼                                          │
  [결과] 골드·장비·크로노 조각·그림자 추월 보너스 ─────────┘
            │
            └─ (오프라인) 야영지 자동 보상 누적 → 재접속 동기
```

- **세션 루프(5분)**: 이동 → 처치 → 레벨업 → 룬 선택 → 배치 → 더 강해진 빌드로 웨이브 돌파.
- **메타 루프(하루)**: 일일 퀘스트 → 소환/합성 → 새 스테이지 해금 → 오프라인 보상.
- **장기 루프(시즌 28일)**: 시즌 패스, 무한의 탑 순위, 주간 거울의 시련.

## 4. 전투 시스템

### 4.1 조작
- **화면 아무 곳이나 드래그** = 가상 조이스틱(손을 뗀 위치에 다시 생성되는 플로팅 방식).
- 기본 공격: 가장 가까운 적을 자동 공격(무기 종류에 따라 형태가 다름).
- 스킬: **룬 시계에 의해 자동 발동**. 플레이어가 하는 일은 **이동(회피·포지셔닝)** 과 **빌드(선택·배치)** 두 가지뿐.
- 화면: 세로(Portrait) 고정. 전투 필드는 화면보다 넓은 원형 아레나(반지름 1.5화면), 카메라는 기사 추적.

### 4.2 스테이지 구성
| 항목 | 값 |
|---|---|
| 한 스테이지 | 10웨이브 × 30초 = 5분 |
| 웨이브 5 | 미니보스 (처치 시 보물상자: 룬 1개 추가 선택) |
| 웨이브 10 | 챕터 보스 (보스 처치 = 클리어) |
| 챕터 | 챕터당 10스테이지, 출시 시 10챕터(100스테이지) + 무한의 탑 |
| 실패 | 사망 시 1회 부활(광고 또는 크리스탈 50). 실패해도 획득 재화의 50% 지급 |

### 4.3 적 (글리치)
기하학 도형 기반. 형태 = 행동 패턴을 한눈에 알 수 있도록 설계.

| 형태 | 이름 | 행동 | 등장 |
|---|---|---|---|
| ▲ 삼각 | 스파이크 | 직진 돌진 | 1챕터~ |
| ■ 사각 | 블록 | 느림, 고체력, 밀치기 저항 | 1챕터~ |
| ● 원 | 버블 | 사망 시 작은 원 3개로 분열 | 2챕터~ |
| ◆ 마름모 | 샤드 | 거리 유지하며 탄 발사 | 3챕터~ |
| ⬡ 육각 | 코어 | 주변 적에게 보호막 부여 | 5챕터~ |
| ✦ 별 | 노바 | 접근 후 자폭 (경고 원 표시) | 6챕터~ |
| 보스 | 시계 파괴자 등 10종 | 챕터별 고유 패턴 2~3개 | 챕터 보스 |

- 동시 화면 적 수 상한: 250 (성능 보장, [04-technical-design.md](04-technical-design.md) 참고)

### 4.4 성장(전투 중)
- 적 처치 → **경험치 결정** 드롭 → 흡수 반경 내 자동 흡수.
- 레벨업 시 게임 일시정지 → **룬 3개 중 1개 선택** (광고 시청 시 1회 리롤, 판당 1회).
- 선택한 룬은 **룬 시계에 직접 배치**(드래그) 또는 "자동 배치"(추천 위치) 선택 가능.
  → 초보자는 자동 배치로 편하게, 숙련자는 수동 배치로 최적화.

## 5. ★ 신규 개념 ① — 룬 시계 (Rune Clock)

### 5.1 규칙
- 룬 시계는 **12칸**(1시~12시)의 원형 슬롯.
- **시곗바늘**이 기본 **6초에 한 바퀴** 회전(칸당 0.5초). 바늘이 칸을 지날 때 그 칸의 룬이 발동.
- 빈 칸은 아무것도 하지 않음 → 룬이 늘수록 발동 밀도가 증가.
- 같은 룬을 이미 배치된 룬 위에 놓으면 **레벨업**(Lv1~Lv5, Lv5는 "각성" 효과 추가).

### 5.2 배치 규칙 (빌드의 깊이)
| 규칙 | 조건 | 효과 |
|---|---|---|
| **연쇄 (Chain)** | 룬 A 다음 칸(시계 방향)에 반응 가능한 룬 B | B 발동 시 **원소 반응** 발생 (아래 표) |
| **공명 (Resonance)** | 정반대 칸(n, n+6)에 같은 원소 | 두 룬 모두 피해 +30% |
| **정오 (High Noon)** | 12시 칸 | 해당 룬 효과 ×2 (한 바퀴에 한 번만 오는 "필살기 칸") |
| **템포 (Tempo)** | 템포 계열 룬 보유 | 바늘 회전 속도 증가 (최대 3초/바퀴) |

### 5.3 원소 (6종 — 색 + 모양 아이콘으로 구분, 색약 대응)
화(Fire, 삼각 불꽃) · 빙(Frost, 눈꽃) · 뇌(Volt, 번개) · 풍(Wind, 소용돌이) · 광(Light, 태양) · 암(Void, 초승달)

### 5.4 원소 반응 표 (A → B 순서, 시계 방향 인접 시)
| A → B | 반응 | 효과 |
|---|---|---|
| 화 → 풍 | 화염폭풍 | B의 범위 +50%, 화상 부여 |
| 풍 → 화 | 불씨 확산 | 화상 입은 적 주변으로 화상 전파 |
| 빙 → 뇌 | 초전도 | 빙결된 적에게 뇌 피해 ×2 |
| 뇌 → 빙 | 결정 방전 | 빙결 지속 +1초, 감전 연쇄 +2 |
| 화 → 빙 / 빙 → 화 | 증기 폭발 | B 위치에 추가 폭발(ATK 150%) |
| 광 → 암 / 암 → 광 | 일식 | 화면 전체 적 0.5초 정지 + 피해 (쿨 12초) |
| 풍 → 뇌 | 뇌운 | 뇌 공격이 3회 튕김 |
| 암 → 모든 원소 | 공허 흡수 | B의 피해 10%만큼 체력 회복 |

> 반응은 **시각적으로 크게** 표현한다(반응 이름 팝업 + 컬러 섬광). 플레이어가 "내가 조합을 만들었다"는
> 감각을 명확히 받는 것이 목적.

### 5.5 룬 목록 (출시 24종 = 원소당 4종)
| 원소 | 룬 (공격형 2 / 유틸형 1 / 템포·특수 1) |
|---|---|
| 화 | 화염구(투사체), 불기둥(장판), 열정(ATK +10% 버프 3초), 과열(템포: 회전 +10%, 피격 시 화상) |
| 빙 | 얼음창(관통), 서리 고리(원형 둔화), 빙벽(보호막), 영구동토(정오 칸에서 전체 빙결 1초) |
| 뇌 | 번개(무작위 3타), 전류망(연결 피해), 가속(이속 +30% 3초), 과충전(템포: 회전 +15%) |
| 풍 | 회오리(끌어당김), 바람 칼날(부채꼴), 순풍(흡수 반경 +50%), 돌풍(적 밀치기) |
| 광 | 성광(주변 폭발), 빛의 창(직선 대형), 치유(HP 5% 회복), 축복(다음 룬 효과 +50%) |
| 암 | 그림자 칼(추적탄), 블랙홀(흡입 후 폭발), 흡혈(피해 흡혈 3초), 시간 도둑(적 이속 -20% 3초) |

### 5.6 왜 재미있는가 (설계 의도)
- 한눈에 읽히는 **리듬**: 시곗바늘 = 메트로놈. 발동 타이밍이 보이므로 "3초 뒤 블랙홀 → 그 다음 폭발" 을
  예측하고 적을 모는 **포지셔닝 플레이**가 생긴다.
- **12칸 제약**이 선택을 의미 있게 만든다 (무엇을 버리고 무엇을 레벨업할지).
- 빌드 공유 욕구: "내 시계" 스크린샷 공유 기능 → 바이럴 (결과 화면에 시계 이미지 저장/공유 버튼).

## 6. ★ 신규 개념 ② — 그림자 라이벌 (Shadow Rival)

### 6.1 그림자 레이스 (모든 스테이지 재도전 시)
- 스테이지를 한 번 클리어하면, 이후 같은 스테이지에 **"최고 기록 시간선의 나"** 가 반투명 그림자로 함께 등장.
- 그림자는 **이전 플레이의 이동 경로 기록(100ms 샘플)을 재생**하며, 전투에 간섭하지 않는다(시각 전용).
- 화면 상단에 **처치 수 비교 게이지**: 나 vs 그림자.
- 웨이브 종료 시점마다 처치 수가 그림자보다 많으면 **추월 스택** +1 (스택당 골드 +3%, 최대 10).
- 전 웨이브 추월 = **"완벽한 시간선"** 달성 → 크로노 조각 보너스 + 그림자 기록 갱신.
- 효과: 이미 깬 스테이지의 **반복 플레이(파밍)에 긴장감**을 부여. 서버 없이 경쟁감 제공.

### 6.2 거울의 시련 (주간 콘텐츠)
- 매주 월요일 오픈. **나의 기사(스탯·장비)와 내가 가장 많이 사용한 룬 시계 배치를 복제한 "거울 기사"** 와 1:1 결투.
- 거울 기사는 AI로 조작(회피·추적 패턴). 매 승리마다 거울 기사가 +10% 강해지는 5단계.
- 보상: 주간 크리스탈, 전용 코스튬 조각.
- 메시지: **"오늘의 나는 어제의 나보다 강한가?"** — 스스로 빌드를 개선하게 만드는 동기.

### 6.3 기술 메모
- 그림자 데이터: 5분 × 10Hz × (x,y short 2개) ≈ 12KB/스테이지 → 최근 클리어 기록만 보관, 최대 100개 ≈ 1.2MB 이내.
- 거울 기사는 서버 없이 **로컬 데이터만으로 생성** (내 스탯 스냅샷 + 사용 빈도 통계).

## 7. 캐릭터 성장 (단일 기사)

| 시스템 | 재화 | 내용 |
|---|---|---|
| **레벨** | 계정 경험치 (전투) | 레벨마다 기본 스탯 상승, 콘텐츠 해금 |
| **훈련** | 골드 | ATK / HP / DEF / 치명타 4종 무한 강화 (방치형 "숫자 성장" 담당) |
| **장비** | 소환·드롭 | 6부위: 무기, 투구, 갑옷, 장갑, 신발, 목걸이 |
| **장비 합성** | 동일 장비 3개 | 등급 상승 (일반→희귀→영웅→전설→신화) |
| **장비 강화** | 골드 + 강화석 | 부위별 레벨 (장비 교체해도 부위 레벨 유지 → 교체 부담 제거) |
| **룬 숙련** | 크로노 조각 | 룬별 영구 레벨(시작 시 룬 Lv 보너스) + **시작 룬 슬롯** 해금 (전투 시작 시 1~3개 룬을 미리 배치) |
| **코스튬** | 크리스탈/이벤트 | 외형 + 공격 이펙트 색 변경 (능력치 없음 또는 수집 보너스 소량) |

### 7.1 무기 계열 (기본 공격 형태 결정 — 무기 교체만으로 플레이감 변화)
| 무기 | 기본 공격 | 특성 |
|---|---|---|
| 장검 | 전방 부채꼴 베기 | 균형형 (기본 지급) |
| 창 | 직선 관통 찌르기 | 관통 |
| 쌍검 | 빠른 2연타 근접 | 공속 |
| 석궁 | 원거리 단일 | 사거리 |
| 시계추 철퇴 | 주변 회전 타격 | 광역 |
| 크로노 지팡이 | 시곗바늘 발동 시 추가 마탄 | 룬 시너지 (전설 전용) |

### 7.2 장비 등급 & 특수 옵션
- 일반/희귀/영웅: 기본 스탯만.
- 전설: 고유 옵션 1개 (예: "정오 칸 효과 ×2.5", "화 원소 반응 피해 +40%").
- 신화: 고유 옵션 2개 + 외형 변화. **신화는 소환에서 직접 나오지 않고, 전설 3개 합성으로만 획득** (갓챠 의존도 완화).

## 9. 중독성(리텐션) 설계

윤리 원칙: **"시간을 빼앗는" 장치가 아니라 "다시 오고 싶게 만드는" 장치**만 사용한다.
과금 압박형 다크패턴(가짜 타이머, 오해를 부르는 가격 표기 등)은 사용하지 않는다.

| 심리 기제 | 구현 |
|---|---|
| 짧은 보상 주기 | 30초 웨이브, 평균 20초마다 레벨업, 5분마다 결과 보상 |
| 가변 보상 | 장비 드롭, 보물상자, 소환 연출의 등급 암시 |
| 목표 기울기(Goal Gradient) | 스테이지 진행바, 패스 레벨, "다음 해금까지 N" 표시 |
| 니어 미스 | 보스 HP 5% 남기고 사망 시 "거의 다 왔다!" + 부활 제안 |
| 자기 경쟁 | 그림자 라이벌, 거울의 시련 |
| 손실 회피(부드럽게) | 야영지 12시간 상한 → 알림으로 "야영지가 가득 찼어요" |
| 연속성 | 7일/28일 출석, 일일 퀘스트 5개 완료 보너스 |
| 수집 | 룬 도감, 장비 도감(수집 보너스 소량), PGS 업적 50개 |
| 창의·표현 | 룬 시계 배치 공유 이미지 |

## 10. 소셜·바이럴 (서버 없이 가능한 것만)
- **PGS 리더보드**: 무한의 탑 최고 층, 주간 거울의 시련 최단 시간.
- **PGS 업적**: 50개 (원소 반응 발견, 챕터 클리어, 수집 등).
- **빌드 공유**: 결과 화면의 룬 시계 + 스탯을 이미지 카드로 생성 → Android 공유 시트.
- **빌드 코드**: 룬 배치를 짧은 문자열(예: `CK1-F3W4...`)로 공유 → 다른 유저가 "추천 배치"로 불러오기(자동 배치 가이드로 사용).
- 스토어 리뷰 요청: In-App Review API, **보스 첫 처치 직후 등 긍정 순간**에만, 최대 연 3회.
