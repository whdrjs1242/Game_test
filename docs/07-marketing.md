# 07. 마케팅 계획 — 1인 운영 · 저예산

> 조건: **1인 운영(소셜 + 인스타그램)**, 예산 **월 10만 원 이하 + 수익금의 10~20% 재투자**.
> 결론: 유료 광고로 설치를 사는 방식은 불가능한 규모다. 따라서 **게임 자체가 홍보물을 만들어 내도록** 설계하고,
> 1인이 하루 30~60분 안에 운영할 수 있는 루틴만 남긴다.

---

## 1. 현실적인 목표 재설정

| 구분 | 기존 가정 | 조정 목표 |
|---|---|---|
| 순위 | 전체 1위 경쟁 | 1차: **"신규 인기 게임" / 액션·롤플레잉 카테고리 신규 차트 진입**, 2차: 카테고리 상위 50 |
| 설치 | 대규모 UA | 출시 3개월 누적 1~3만 (자연 유입 + 바이럴 중심) |
| 확장 | — | D7 20% 이상 + 결제 전환 3% 이상이 확인되면 수익 재투자로 광고 확대 |

- Google Play 는 **리텐션·평점·설치 속도**가 좋은 신작을 추천 영역에 노출한다. 저예산에서는 광고비보다 **지표 품질**이 순위를 만든다.
- 모든 마케팅 결정은 이 원칙을 따른다: **"광고비 1원보다 D1 리텐션 1%p가 더 중요하다."**

---

## 2. 게임에 넣는 바이럴 장치 (개발 범위에 포함)

| 기능 | 설명 | 개발 마일스톤 |
|---|---|---|
| **하이라이트 릴스 자동 생성** ★ | 엔진이 결정적(시드+입력 로그)이므로 판 종료 후 **마지막 원소 반응 연쇄 8~15초를 오프스크린으로 다시 렌더링 → 1080×1920 MP4** (MediaCodec, 화면 녹화 권한 불필요). 하단에 게임명·"Google Play에서 검색" 워터마크 | M7 |
| 빌드 카드 | 룬 시계 + 스탯 + 빌드 코드를 **1080×1350 (인스타 피드 비율)** 이미지로 생성 | M7 |
| 빌드 코드 | `CK1-...` 문자열 → 댓글로 공유, 다른 유저가 불러오기 | M7 |
| 공유 보상 | 하루 1회 공유 시 크리스탈 30 (공유 여부는 확인 불가하므로 "공유 시트 열기" 기준, 소액만) | M7 |
| 사전예약 보상 | 출시 시 전원 지급 전설 선택권 1장 (Play 사전예약 보상 기능) | M11 |
| 쿠폰 코드 | Remote Config 에 **해시된 코드 목록** 배포, 계정당 1회 사용 (서버 없이 운영) → 인플루언서·이벤트용 | M9 |
| 리뷰 요청 | 긍정 순간(첫 보스 처치, 첫 전설 획득)에만 In-App Review | M10 |

> 하이라이트 릴스는 1인 마케팅의 핵심이다. 운영자가 영상을 편집하지 않아도 **유저와 운영자가 같은 도구로 릴스를 만든다.**

## 3. 채널 운영 (1인 루틴)

| 채널 | 역할 | 빈도 | 소요 |
|---|---|---|---|
| **인스타그램 릴스** | 메인. 원소 반응 연쇄, "이 배치 이길 수 있음?" 챌린지 | 주 4~5회 | 1회 10분 (게임 내 릴스 생성 기능 사용) |
| 인스타 피드/스토리 | 빌드 카드, 패치 노트, 투표("다음 신규 룬 원소는?") | 주 2~3회 | 1회 5분 |
| 유튜브 쇼츠 · 틱톡 | 같은 릴스 **재업로드** (추가 제작 없음) | 릴스와 동일 | 1회 2분 |
| 커뮤니티 (디스코드 또는 카카오 오픈채팅 1곳) | 버그 제보, 빌드 공유, 코어 유저 관리 | 매일 확인 | 10~15분 |
| 개발 일지 (인스타 + 커뮤니티) | "AI(Claude Code)로 1인 개발 중" 과정 공유 → 출시 전 팔로워 확보 | 주 1회 | 20분 |

### 3.1 콘텐츠 기둥 (릴스 주제 4가지를 돌려가며)
1. **쾌감**: 화면을 가득 채우는 원소 반응 연쇄 (첫 1초에 폭발)
2. **퍼즐**: "12시에 뭘 넣어야 할까?" 빌드 퀴즈 → 댓글 참여 유도
3. **도전**: 그림자 라이벌 추월 장면, 거울의 시련 역전승
4. **개발 이야기**: AI로 게임을 만드는 1인 개발자 스토리 (출시 전 가장 강력한 주제)

### 3.2 해시태그·문구
- 고정: `#크로노나이트 #모바일게임 #인디게임 #1인개발 #로그라이트`
- 첫 줄 문구는 행동 유도형: "이 배치로 보스 잡을 수 있는 사람?" / "12시 칸의 정답은?"

## 4. 예산 배분

### 4.1 출시 전 ~ 출시 3개월 (월 10만 원 이하)
| 항목 | 월 금액 | 용도 |
|---|---|---|
| 인스타 릴스 부스트 | 60,000원 | **자연 반응이 가장 좋았던 릴스 1~2개만** 부스트 (1일 3,000원 × 20일). 목표: 팔로워·사전예약 |
| 마이크로 인플루언서 | 0~30,000원 | 팔로워 1천~1만 게임 계정에 쿠폰 코드 + 소액/기프티콘 협업 |
| 예비 | 10,000원 | 테스트 광고 소재 비교 |
| 1회성 | 25달러 | Play 개발자 등록 (출시 전 1회) |

- 부스트는 **"오가닉 반응 상위 10% 영상만"** — 반응 없는 영상에 돈을 쓰지 않는다.
- 설치 캠페인(Google App Campaign 등)은 이 예산으로는 학습이 안 되므로 **수익 재투자 단계부터** 시작.

### 4.2 수익 발생 후 (월 10만 원 + 수익의 10~20%)
| 월 수익(순) | 재투자 비율 | 추가 예산 | 사용처 |
|---|---|---|---|
| ~100만 원 | 10% | ~10만 원 | 릴스 부스트 확대 |
| 100~500만 원 | 15% | 15~75만 원 | Google App Campaign(설치) 테스트 시작, 인플루언서 |
| 500만 원~ | 20% | 100만 원~ | 앱 캠페인 + 인플루언서 정례화, 글로벌 현지화(영·일) 스토어 |

**재투자 규칙 (손실 방지)**
- 광고 채널별 **D7 ROAS**(광고비 대비 7일 매출)를 확인해 30% 미만 채널은 2주 후 중단.
- 사용자 1명 획득 단가(CPI)가 **1인당 평균 30일 매출(ARPU D30)** 을 넘는 채널은 확대하지 않는다.
- 매출 인식: Google 수수료(15% 수수료 프로그램 등록 시 연 매출 첫 100만 달러까지 15%) 제외 후 순수익 기준으로 비율을 계산한다.

## 5. 출시 타임라인 (마케팅)

| 시점 | 할 일 |
|---|---|
| 개발 M2 (룬 시계 완성) | 인스타 계정 개설, 개발 일지 시작, 첫 원소 반응 영상 업로드 |
| 개발 M7 | 게임 내 릴스 생성 기능으로 주 4회 업로드 시작, 커뮤니티 개설 |
| 개발 M10 | 비공개 테스트 모집 (커뮤니티·인스타 팔로워 대상) — Play 비공개 테스트 요건 충족에도 활용 |
| 출시 4주 전 | Play **사전예약** 오픈, 사전예약 보상 공지, 부스트 집중 |
| 출시일 | 사전예약자 자동 설치 → 초기 설치 속도 확보, 리뷰 응답 매일 |
| 출시 후 1~4주 | 리뷰 100% 응답, 버그 패치 주 1회, "첫 시즌" 공지 |
| 출시 후 매 시즌(28일) | 신규 룬 공개 릴스 → 빌드 챌린지 이벤트(쿠폰 보상) |

## 6. ASO (무료, 가장 효율 높음)
- 스토어 문구·스크린샷 방향은 [03-design-ux.md §7](03-design-ux.md) 참고.
- Play Console **스토어 등록정보 실험(A/B)** 을 무료로 사용: 아이콘 2종, 첫 스크린샷 2종부터 비교.
- 키워드: "로그라이트", "한손 게임", "방치형", "서바이벌", "룬" 을 제목·짧은 설명·긴 설명에 자연스럽게 배치.
- 평점 4.5 이상 유지가 추천 노출의 핵심 → 리뷰 응답·버그 패치 우선.
