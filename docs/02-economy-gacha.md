# 02. 경제 · 갓챠 · 비즈니스 모델

> 원칙: **갓챠는 "살짝"** — 무과금도 모든 콘텐츠를 즐길 수 있고, 과금은 "시간 단축과 수집"을 판다.
> 모든 수치는 `app/src/main/assets/balance/*.json` 으로 데이터화하고 Firebase Remote Config 로 원격 조정 가능하게 한다.

## 1. 재화

| 재화 | 종류 | 주 획득처 | 주 사용처 | 보유 상한 |
|---|---|---|---|---|
| 골드 | 소프트 | 전투, 야영지, 요일 던전(질주) | 훈련, 오브·펫 레벨 | 없음 (Long) |
| 크리스탈 | 하드(유료) | 결제, 퀘스트, 업적, 시련, 패스 | 소환, 부활, 코스튬, 패키지 | 없음 |
| 크로노 조각 | 성장 | 조각의 방, 그림자 추월, 패스 | 룬 숙련, 시작 룬 슬롯 | 없음 |
| 오브 합성석 · 펫 먹이 | 성장 | 요일 던전, 분해, 야영지 | 오브 강화, 펫 레벨 | 없음 |
| 시간 결정 | 성장(희귀) | 레전드 × 3 합성 부산물 | 레전드·히든·유일 ★ 승급 | 없음 |
| 소환권 (오브/룬/펫) | 소환 | 이벤트, 패스, 출석, 주간 미션 | 해당 배너 1회 | 999 |
| 마일리지 | 천장 | 배너별 소환 1회당 1 | 120점 = 레전드 선택권 | 소멸 없음 (다음 시즌 이월) |

- 유료 크리스탈과 무료 크리스탈은 **내부적으로 분리 기록**(환불·청약철회 대응, 법적 요구)하되 UI 에는 합산 표시.
  사용 시 **무료분 우선 차감**.

## 2. 소환 (갓챠) — 오브 / 룬 / 펫 3개 배너

> 등급: 노멀 · 매직 · 레어 · 유니크 · 레전드 (+ 룬 배너 전용 **유일**). 히든 등급은 **소환 불가**(조건 달성 + 고정 레시피).
> 상세 표·유일룬·합성 규칙: [08-items-skills.md §6~7](08-items-skills.md).

### 2.1 가격
| 구분 | 비용 |
|---|---|
| 1회 | 크리스탈 150 또는 해당 배너 소환권 1 |
| 10회 | 크리스탈 1,350 (10% 할인) |
| 일일 무료 | 광고 시청 1회 = 원하는 배너 1회 (1일 1회) |

### 2.2 확률 — 게임 내 소환 화면·웹페이지에 동일하게 공개
| 등급 | 오브 | 룬 | 펫 |
|---|---|---|---|
| 노멀 | 45.0% | 44.97% | 45.0% |
| 매직 | 30.8% | 30.8% | 30.8% |
| 레어 | 18.0% | 18.0% | 18.0% |
| 유니크 | 5.0% | 5.0% | 5.0% |
| 레전드 | 1.2% | 1.2% | 1.2% |
| 유일 | — | 0.03% (미보유 유일룬 중 균등) | — |

- 등급 내 개별 아이템 확률은 **균등**, 아이템별 확률표 전체를 "확률 상세" 화면에 공개.

### 2.3 보장 장치
| 장치 | 내용 |
|---|---|
| 10회 보장 | 10회 소환 시 레어 이상 1개 확정 |
| 레전드 천장 | 배너별로 레전드 미획득 79회 연속 시 **80번째에 레전드 확정** |
| 마일리지 | 배너별 1회당 1점, **120점 = 해당 배너 레전드 1개 선택** |
| 픽업 | 시즌 픽업 레전드 1종: 레전드 획득 시 50% 픽업, 실패 시 다음 레전드 픽업 확정 |
| 유일 천장 | 룬 배너 1,000회 누적 시 미보유 유일룬 선택권(획득 시 초기화) |
| 중복 보정 | 중복은 ★ 승급·합성 재료로 활용 — "꽝" 없음 |

> 기대값: 레전드 평균 약 **52회**(Σ 0.988^k, k=0..79), 최대 80회. 10회(1,350 크리스탈) ≈ ₩8,100 기준 레전드 1개 기대 비용 ≈ ₩42,000, 최대 ≈ ₩65,000.
> 유일룬은 레전드 대비 약 **16배** 어려움(기대 약 860회) — 무과금 경로는 무한의 탑 200층 1회.

### 2.4 합성 (갓챠 의존도 완화 장치)
| 합성식 | 결과 |
|---|---|
| 같은 룬 × 3 (같은 등급) | 같은 룬의 다음 등급 (100%) |
| 같은 등급 오브 × 3 | 다음 등급 오브 1종 (같은 계열 60% / 무작위 40%, 등급 내 균등 — 공시) |
| 같은 등급 펫 × 3 | 다음 등급 펫 1종 (균등 — 공시) |
| 레전드 × 3 | 시간 결정 1 |
| 분해 | 크로노 조각 · 골드 |
| ??? (히든) | 비공개 고정 레시피 — [09 문서](09-hidden-codex.md) |

- 노멀~레어는 **스토리·요일 던전 드롭으로도 획득** → 무과금도 합성으로 레전드까지 도달 가능(느림).

### 2.5 소환 연출 (재미 요소, 확률에는 영향 없음)
1. 오브: 시계탑 문 / 룬: 룬 시계 회전 / 펫: 알 부화. 바늘이 멈추는 시각이 등급을 **암시**: 3시(레어) / 6시(유니크) / 12시(레전드 금빛 + 종소리).
2. 10회 소환은 최고 등급만 확대 연출, 나머지는 빠르게 펼침(스킵 버튼 항상 제공).
3. 유일룬: 시계탑이 **13번 종**을 치는 전용 연출. 히든 각성은 합성 화면의 ??? 슬롯이 깨지는 연출(획득의 절정 = 플레이의 결과).

### 2.6 난수 규칙 (공정성)
- 소환 결과는 **클라이언트 내 결정**(서버 없음). `SecureRandom` 기반 시드로 매 소환마다 추첨.
- 소환 결과를 결정한 후 세이브를 **먼저 커밋**하고 연출을 재생 → 앱 강제 종료로 결과 되돌리기 방지.
- 확률 테이블은 단위 테스트에서 배너별 100만 회 시뮬레이션으로 공시 확률과 오차 ±0.1%p(유일은 ±0.01%p) 이내인지 검증.

## 4. 무과금 수급량 (밸런스 기준선)

| 출처 | 크리스탈/일 (평균) |
|---|---|
| 일일 미션 3개 완료 | 60 |
| 주간 미션 (÷7) | 40 |
| 거울의 시련 (÷7) | 20 |
| 업적·챕터 보상 (초반 30일 평균) | 40 |
| **합계** | **약 160/일 → 10회 소환(1,350) 약 8~9일에 1회** |

- 추가: 일일 무료 소환 1회, 출석·패스 무료 트랙 티켓 → 무과금 한 달 **약 60회 소환**(3배너 합산) ≈ 레전드 약 1개.
- 과금 유저(월정액 + 패스, 월 ₩16,500) 한 달 **약 120회 소환** ≈ 레전드 2~3개.
- 목표: 과금 유저가 무과금 대비 약 **1.5~2배 빠른 진행**. 그 이상의 격차는 만들지 않는다(PvP 없음 → 격차가 불만으로 이어지는 구조 자체를 차단).

## 5. 밸런스 공식 (초기값, JSON 데이터화)

> 기호: `s` = 스테이지 번호(1~), `w` = 웨이브(1~10), `L` = 레벨

### 5.1 적
```
enemyHp(s, w)   = baseHp[type]  * 1.115^(s-1) * (1 + 0.09*(w-1))
enemyAtk(s, w)  = baseAtk[type] * 1.10^(s-1)  * (1 + 0.05*(w-1))
bossHp(s)       = 60 * enemyHp(s, 10) (챕터 보스), 미니보스 = 20 * enemyHp(s, 5)
spawnPerSec(w)  = 1.5 + 0.35*(w-1)          (상한: 동시 250마리)
```
| 타입 | baseHp | baseAtk | 속도(유닛/초) |
|---|---|---|---|
| 스파이크 ▲ | 10 | 5 | 2.4 |
| 블록 ■ | 40 | 8 | 1.2 |
| 버블 ● | 18 (분열체 5) | 4 | 1.8 |
| 샤드 ◆ | 14 | 6 (탄) | 1.6 |
| 코어 ⬡ | 30 | 3 | 1.4 |
| 노바 ✦ | 12 | 30 (자폭) | 2.8 |

### 5.2 기사
```
atk(L, t)   = 10 + 2*L + trainAtk(t)       trainAtk(t) = 3*t        (t = 훈련 레벨)
hp(L, t)    = 100 + 20*L + trainHp(t)      trainHp(t)  = 25*t
trainCost(t)= floor(50 * 1.075^t)          (골드)
accountExpToNext(L) = floor(100 * L^1.6)
```

### 5.3 전투 내 레벨업
```
runExpToNext(n) = 5 + 4*n + floor(0.4*n^2)     (n = 판 내 레벨)
목표: 5분 한 판에 판 내 레벨 약 15~18 도달 → 룬 선택 15~18회 (12칸 + 레벨업 중복분)
```

### 5.4 룬
```
runeDamage(lv) = baseRatio * ATK * (1 + 0.35*(lv-1))        (Lv1~5)
각성(Lv5): 룬별 고유 효과 추가 (예: 화염구 → 착탄 시 소형 폭발 3개)
runeMastery 보너스: 숙련 레벨당 해당 룬 피해 +4%, 최대 20레벨
```

### 5.5 보상
```
stageGold(s)       = floor(120 * 1.09^(s-1))
campGoldPerMin(m)  = floor(4 * 1.085^(m-1))     (m = 최고 클리어 스테이지)
campCapMinutes     = 720 (월정액 960)
failRewardRatio    = 0.5
shadowOvertakeGold = +3% / 스택, 최대 10 스택
```

### 5.6 밸런스 검증 방법
- 엔진이 순수 Kotlin 이므로 **헤드리스 시뮬레이터**로 "표준 성장 곡선의 봇"이 스테이지 1~100을 각 200회 플레이 →
  스테이지별 클리어율이 **목표 곡선**(신규 스테이지 첫 도전 클리어율 40~60%) 안에 드는지 CI 에서 확인.
- 병목 구간(클리어율 < 25%)이 생기면 공식 계수를 조정하고 리포트를 `docs/balance-report.md` 로 자동 생성.
