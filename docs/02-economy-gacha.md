# 02. 경제 · 갓챠 · 비즈니스 모델

> 원칙: **갓챠는 "살짝"** — 무과금도 모든 콘텐츠를 즐길 수 있고, 과금은 "시간 단축과 수집"을 판다.
> 모든 수치는 `app/src/main/assets/balance/*.json` 으로 데이터화하고 Firebase Remote Config 로 원격 조정 가능하게 한다.

## 1. 재화

| 재화 | 종류 | 주 획득처 | 주 사용처 | 보유 상한 |
|---|---|---|---|---|
| 골드 | 소프트 | 전투, 야영지, 황금 시계 던전 | 훈련, 장비 강화 | 없음 (Long) |
| 크리스탈 | 하드(유료) | 결제, 퀘스트, 업적, 시련, 패스 | 소환, 부활, 코스튬, 패키지 | 없음 |
| 크로노 조각 | 성장 | 조각의 방, 그림자 추월, 패스 | 룬 숙련, 시작 룬 슬롯 | 없음 |
| 강화석 | 성장 | 조각의 방, 분해, 야영지 | 장비 부위 강화 | 없음 |
| 소환 티켓 | 소환 | 이벤트, 패스, 출석 | 장비 소환 1회 | 999 |
| 마일리지 | 천장 | 소환 1회당 1 | 전설 선택권 교환 | 시즌 종료 시 미사용분은 **다음 시즌으로 이월** |

- 유료 크리스탈과 무료 크리스탈은 **내부적으로 분리 기록**(환불·청약철회 대응, 법적 요구)하되 UI 에는 합산 표시.
  사용 시 **무료분 우선 차감**.

## 2. 장비 소환 (갓챠) — "별의 시계탑 소환"

### 2.1 가격
| 구분 | 비용 |
|---|---|
| 1회 | 크리스탈 300 또는 소환 티켓 1 |
| 10회 | 크리스탈 2,700 (10% 할인) |
| 일일 무료 | 광고 시청 1회 = 1회 소환 (1일 1회) |

### 2.2 확률 (기본 배너) — 게임 내 소환 화면·웹페이지에 동일하게 공개
| 등급 | 확률 |
|---|---|
| 일반 | 55.0% |
| 희귀 | 30.0% |
| 영웅 | 12.5% |
| 전설 | 2.5% |
| 신화 | 0% (소환 불가, 합성 전용) |

- 등급 내 개별 아이템 확률은 **균등**, 아이템별 확률표 전체를 "확률 상세" 화면에 공개.

### 2.3 보장 장치
| 장치 | 내용 |
|---|---|
| 10회 보장 | 10회 소환 시 영웅 이상 1개 확정 |
| 전설 천장 | 전설 미획득 상태로 49회 연속 시 **50번째 소환에서 전설 확정** (카운터는 배너 공통, 전설 획득 시 0으로 초기화) |
| 마일리지 | 소환 1회당 1점, **100점 = 원하는 전설 장비 1개 선택** |
| 픽업 배너 | 시즌 픽업 전설 1종: 전설 획득 시 50% 확률로 픽업, 픽업 실패 시 다음 전설은 픽업 확정 |
| 중복 보정 | 중복 장비는 합성 재료로 자동 활용되므로 "꽝"이 없음 |

> 기대값: 전설 평균 약 **29회**(천장 반영: Σ 0.975^k, k=0..49 ≈ 28.7), 최대 50회 보장.
> 10회 소환(2,700 크리스탈) ≈ ₩16,000 기준 전설 1개 기대 비용 ≈ ₩46,000, 최대 ≈ ₩81,000.

### 2.4 합성 (갓챠 의존도 완화 장치)
| 합성식 | 결과 |
|---|---|
| 같은 장비 × 3 (일반/희귀/영웅) | 다음 등급의 같은 장비 |
| 전설 장비 A + 같은 부위 전설 × 2 (종류 무관) | 신화 A |
| 불필요 장비 분해 | 강화석 + 골드 |

- 일반~영웅은 **스테이지 드롭으로도 획득** → 무과금도 합성으로 전설까지 도달 가능(느림).

### 2.5 소환 연출 (재미 요소, 확률에는 영향 없음)
1. 시계탑 문이 열리고 바늘이 회전 → 멈추는 시각이 등급을 **암시**: 3시(희귀 파랑) / 6시(영웅 보라) / 12시(전설 금빛 + 종소리).
2. 10회 소환은 결과 카드 10장 중 최고 등급만 연출 확대, 나머지는 빠르게 펼침(스킵 버튼 항상 제공).
3. 신화는 소환에서 나오지 않으므로 **합성 성공 연출**을 가장 화려하게 만든다(획득의 절정 = 플레이의 결과).

### 2.6 난수 규칙 (공정성)
- 소환 결과는 **클라이언트 내 결정**(서버 없음). `SecureRandom` 기반 시드로 매 소환마다 추첨.
- 소환 결과를 결정한 후 세이브를 **먼저 커밋**하고 연출을 재생 → 앱 강제 종료로 결과 되돌리기(리세마라식 재시도) 방지.
- 확률 테이블은 단위 테스트에서 100만 회 시뮬레이션으로 공시 확률과 오차 ±0.1%p 이내인지 검증.

### 3.2 핵심 상품 (가성비 → 첫 결제 전환 + 재방문 유도)
| 상품 | 가격 | 구성 | 목적 |
|---|---|---|---|
| **스타터 팩** (1회) | ₩1,200 | 크리스탈 300 + 영웅 무기 1 + 소환 티켓 5 | 첫 결제 전환 (가성비 극대화) |
| **월정액 "시계탑 후원"** | ₩5,500 | 즉시 300 + 30일간 매일 100 (총 3,300) + 야영지 상한 12→16시간 | 매일 접속 + 안정 매출 |
| **시즌 패스** (28일) | ₩11,000 | 프리미엄 트랙: 크리스탈 2,000, 티켓 20, 시즌 코스튬, 크로노 조각 | 장기 참여 |
| **광고 제거권** (영구) | ₩7,900 | 보상형 광고를 시청 없이 즉시 보상 수령 | 고래 이전 단계 유저 |
| 성장 팩 (챕터 달성) | ₩5,900~₩33,000 | 챕터 3/5/8 클리어 시 24시간 한정 노출 | 성취 순간 전환 |
| 코스튬 | ₩5,900~₩12,000 | 외형 + 이펙트 (능력치 없음) | 수집·표현 |

- **가짜 할인율·가짜 카운트다운 금지.** "한정" 표기는 실제 기간이 있는 상품에만.
- 모든 가격은 Play Console 현지화 가격표를 사용 (해외는 Google 권장 환산가).

### 3.3 광고 (보상형만, AdMob)

|---|---|---|

## 4. 무과금 수급량 (밸런스 기준선)

| 출처 | 크리스탈/일 (평균) |
|---|---|
| 일일 퀘스트 5종 완료 | 60 |
| 주간 퀘스트 (÷7) | 30 |
| 거울의 시련 (÷7) | 30 |
| 업적·챕터 보상 (초반 30일 평균) | 40 |
| **합계** | **약 160/일 → 10회 소환 약 17일에 1회** |

- 추가: 일일 무료 소환 1회, 출석·패스 무료 트랙 티켓 → 무과금 한 달 **약 50~60회 소환** ≈ 전설 1~2개 보장.
- 과금 유저(월정액 + 패스, 월 ₩16,500) 한 달 **약 100회 소환** ≈ 전설 3개 이상.
- 목표: 과금 유저가 무과금 대비 약 **1.5~2배 빠른 진행**. 그 이상의 격차는 만들지 않는다(PvP 없음 → 격차가 불만으로 이어지는 구조 자체를 차단).

## 5. 밸런스 공식 (초기값, JSON 데이터화)

> 기호: `s` = 스테이지 번호(1~), `w` = 웨이브(1~10), `L` = 레벨

### 5.1 적
```
enemyHp(s, w)   = baseHp[type]  * 1.115^(s-1) * (1 + 0.09*(w-1))
enemyAtk(s, w)  = baseAtk[type] * 1.10^(s-1)  * (1 + 0.05*(w-1))
bossHp(s)       = 60 * enemyHp(s, 10) (챕터 보스), 미니보스 = 20 * enemyHp(s, 5)
spawnPerSec(w)  = 1.5 + 0.35*(w-1)          (상한: 동시 250마리)
```
| 타입 | baseHp | baseAtk | 속도(유닛/초) |
|---|---|---|---|
| 스파이크 ▲ | 10 | 5 | 2.4 |
| 블록 ■ | 40 | 8 | 1.2 |
| 버블 ● | 18 (분열체 5) | 4 | 1.8 |
| 샤드 ◆ | 14 | 6 (탄) | 1.6 |
| 코어 ⬡ | 30 | 3 | 1.4 |
| 노바 ✦ | 12 | 30 (자폭) | 2.8 |

### 5.2 기사
```
atk(L, t)   = 10 + 2*L + trainAtk(t)       trainAtk(t) = 3*t        (t = 훈련 레벨)
hp(L, t)    = 100 + 20*L + trainHp(t)      trainHp(t)  = 25*t
trainCost(t)= floor(50 * 1.075^t)          (골드)
accountExpToNext(L) = floor(100 * L^1.6)
```

### 5.3 전투 내 레벨업
```
runExpToNext(n) = 5 + 4*n + floor(0.4*n^2)     (n = 판 내 레벨)
목표: 5분 한 판에 판 내 레벨 약 15~18 도달 → 룬 선택 15~18회 (12칸 + 레벨업 중복분)
```

### 5.4 룬
```
runeDamage(lv) = baseRatio * ATK * (1 + 0.35*(lv-1))        (Lv1~5)
각성(Lv5): 룬별 고유 효과 추가 (예: 화염구 → 착탄 시 소형 폭발 3개)
runeMastery 보너스: 숙련 레벨당 해당 룬 피해 +4%, 최대 20레벨
```

### 5.5 보상
```
stageGold(s)       = floor(120 * 1.09^(s-1))
campGoldPerMin(m)  = floor(4 * 1.085^(m-1))     (m = 최고 클리어 스테이지)
campCapMinutes     = 720 (월정액 960)
failRewardRatio    = 0.5
shadowOvertakeGold = +3% / 스택, 최대 10 스택
```

### 5.6 밸런스 검증 방법
- 엔진이 순수 Kotlin 이므로 **헤드리스 시뮬레이터**로 "표준 성장 곡선의 봇"이 스테이지 1~100을 각 200회 플레이 →
  스테이지별 클리어율이 **목표 곡선**(신규 스테이지 첫 도전 클리어율 40~60%) 안에 드는지 CI 에서 확인.
- 병목 구간(클리어율 < 25%)이 생기면 공식 계수를 조정하고 리포트를 `docs/balance-report.md` 로 자동 생성.
