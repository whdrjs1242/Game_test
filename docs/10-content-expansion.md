# 10. 콘텐츠 확장 — 요일 던전 미니게임 · 스토리 · 조합형 성장 · 가벼운 미션

> 목표: "매일 들어오고 싶은 이유"를 **숙제가 아니라 놀거리**로 만든다.
> 원칙: 하루 필수 플레이 **15분 이내**, 나머지는 원하는 만큼 더 즐기는 구조.

## 2. 일일 · 주간 미션 (가볍게)

- **일일 미션은 3개만.** 모두 "평소 플레이하면 저절로 채워지는" 항목. 합계 보상 크리스탈 60.
- 특정 콘텐츠 강요 미션(광고 N회 시청, 소환 N회 등) **금지**.
- 놓친 날의 미션은 **최대 2일까지 이월**(하루 빠져도 손해 적음 → 스트레스 감소).

| 일일 미션 풀 (매일 3개 무작위) | 조건 |
|---|---|
| 전투 한 판 | 아무 전투 1회 |
| 반응 탐구 | 원소 반응 50회 |
| 오늘의 던전 | 요일 던전 1회 |
| 그림자 경주 | 그림자 레이스 1회 |
| 성장의 하루 | 훈련·강화·합성 중 아무거나 1회 |

| 주간 미션 (5개, 여유 있게) | 보상 |
|---|---|
| 스토리 3스테이지 진행 / 요일 던전 5회 / 거울의 시련 1단계 / 숨은 시너지 또는 새 반응 1개 발견 / 무한의 탑 3층 갱신 | 크리스탈 300 + 소환권 1 |

## 3. 요일 던전 — 미니게임 3종 ★

"같은 게임, 다른 장르". 모든 미니게임은 **내 기사·오브·펫·액티브 스킬을 그대로 사용**하되 조작과 규칙만 바뀐다. 1판 60~120초, 하루 2회(광고로 +1), 3성 달성 시 소탕 가능.

| 요일 | 던전 | 장르 | 주 보상 |
|---|---|---|---|
| 월 · 목 | **시계탑 질주** | 횡스크롤 러너·액션 | 골드, 펫 먹이 |
| 화 · 금 | **초침 결투장** | 1:1 대전 액션 | 오브 합성 재료, 액티브 스킬 조각 |
| 수 · 토 | **시계판 전술** | 턴제 전략 퍼즐 | 룬 조각, 크로노 조각 |
| 일 | 세 던전 모두 개방 + 보상 1.5배 | — | — |

### 3.1 시계탑 질주 (횡스크롤)
- **화면**: 가로 스크롤(세로 화면 유지, 하단 2/3 사용). 기사가 시계탑 외벽을 자동으로 달린다.
- **조작**: 탭 = 점프(2단), 위로 스와이프 = 오브 상향 공격, 아래 스와이프 = 슬라이드, 액티브 버튼 사용 가능.
- **규칙**: 90초 동안 톱니·추 함정을 피하며 글리치를 베고 골드 톱니를 수집. **룬 시계는 "탑의 큰 시계"** — 바늘이 12시에 오면 화면 전체 보너스 타임(골드 ×2, 5초).
- **변주**: 매주 코스 조합이 바뀜(절차 생성 청크 20종 조합). 3성 조건: 무피격 / 수집 80% / 보스 톱니 파괴.
- **재미 포인트**: 짧은 리듬 액션, 한 손 탭 조작.

### 3.2 초침 결투장 (대전 액션)
- **화면**: 좁은 원형 결투장, 1:1. 상대는 요일마다 바뀌는 **챔피언 글리치**(5종 로테이션, 각자 고유 패턴).
- **조작**: 탭 = 공격(3연타), 길게 누름 = 가드, 좌우 스와이프 = 회피(무적 프레임), 액티브 스킬 = 필살기, 펫 액티브는 자동.
- **규칙**: 3판 2선승, 한 판 45초. **패링**: 상대 공격 직전 0.15초 안에 가드 → "초침 패링"(상대 1초 경직, 룬 1회 발동).
- **룬 시계 역할**: 12칸 대신 **4칸 소형 시계**(3·6·9·12시) — 내 룬 컬렉션에서 4개를 골라 장착.
- **재미 포인트**: 타이밍 싸움, 패링 쾌감. 난이도 3단계 + 주간 "챔피언 각성" 모드(보상 크게).

### 3.3 시계판 전술 (전략)
- **화면**: 시계 문자판 모양의 **12칸 원형 보드** + 중앙 칸. 턴제.
- **규칙**: 적 글리치 무리가 바깥 원에서 중앙(시계탑 심장)으로 진군. 매 턴 **룬 1개를 보드 칸에 배치**(최대 5턴, 5개). 턴 종료마다 **바늘이 3칸 이동**하며 지나간 칸의 룬이 발동. 인접 반응 규칙 동일.
- **목표**: 5턴 후 중앙에 도달한 적 0 = 3성. 매일 **고정 퍼즐 1개 + 무작위 1개**.
- **재미 포인트**: 룬 시계 규칙을 퍼즐로 깊게 이해 → 본 게임 빌드 실력 향상으로 연결. "오늘의 퍼즐" 공유 욕구(정답 인증 인스타 소재).

### 3.4 공통 구현 메모
- 세 미니게임 모두 `:engine` 의 전투 코어(엔티티·충돌·룬 효과)를 재사용하고, **카메라·입력·승리 조건 모듈만 교체**한다 → 개발 비용 억제.
- 각 미니게임은 별도 `GameMode` 구현체(`SideScrollMode`, `DuelMode`, `TacticsMode`).

## 4. 조합형 성장 — "스펙이 아니라 빌드" ★

무한히 숫자만 올리는 구조 대신, **특수효과의 조합**으로 성장 방향이 갈라지게 만든다. 세 개의 층으로 구성한다.

### 4.1 층 ① 효과 태그 공명 (Tag Resonance)
- 오브 특성·룬·펫 패시브·패시브 스킬·각인에는 **효과 태그**가 붙어 있다.
- 장착 중인 효과의 같은 태그 수가 **3 / 5 / 7**에 도달하면 규칙이 바뀌는 공명 보너스가 켜진다. (수치보다 "규칙 변화")

| 태그 | 3개 | 5개 | 7개 |
|---|---|---|---|
| #화상 | 화상이 인접 적에게 번짐 | 화상 적 처치 시 폭발 | 화상 중첩 상한 제거 |
| #빙결 | 빙결 적 넉백 면역 해제 | 빙결 해제 시 파편 | 보스도 0.5초 빙결 |
| #감전 | 감전 적끼리 전류 연결 | 전류 연결 수만큼 피해 | 연결된 적 전부 동시 폭발 |
| #연쇄 | 연쇄 +1 | 연쇄마다 경험치 결정 | 연쇄가 기사에게 돌아와 보호막 |
| #정오 | 12시 칸 효과 +20% | 12시 발동 시 바늘 가속 | 12시가 바퀴당 2번 |
| #템포 | 바늘 속도 +10% | 가속 중 이속 +10% | 최고 속도에서 룬 발동 1회 추가 |
| #그림자 | 그림자 위치에 표식 | 그림자가 적 1기 처치 가능 | 그림자와 나 사이에 번개 |
| #흡혈 | 흡혈 +2% | 최대 HP 초과 흡혈 → 보호막 | 보호막 파괴 시 충격파 |
| #소환 | 소환체 수 +1 | 소환체 사망 시 폭발 | 소환체가 룬 효과 복사(30%) |
| #장판 | 장판 범위 +15% | 장판 겹치면 반응 | 장판이 기사를 따라옴 |
| #처치 | 처치 시 이속 +2%(중첩) | 10연속 처치 시 룬 1회 | 처치마다 바늘 0.1칸 전진 |
| #치명 | 치명 +5% | 치명 시 원소 부여 | 치명 피해가 연쇄로 퍼짐 |

- 공명 UI: 기사 화면에 **태그 별자리 판** — 활성화된 태그가 별자리처럼 연결되어 빛난다(빌드가 한눈에 보임, 공유 이미지로도 활용).

### 4.2 층 ② 각인 — 업적 효과 (Inscriptions)
- 업적을 달성하면 **각인**(작은 규칙 변경 효과)을 얻는다. **3칸 장착**, 언제든 교체.
- 각인은 전투력을 크게 올리지 않지만 **빌드 방향을 바꾼다**. 출시 시 40종, 시즌마다 5종 추가. 예시:

| 업적 | 각인 | 효과 | 태그 |
|---|---|---|---|
| 정오 발동 1,000회 | 정오의 수집가 | 12시 칸 발동 5회마다 추가 발동 1회 | #정오 |
| 무피격 보스 처치 | 흠 없는 갑옷 | 피격이 없으면 10초마다 피해 +5%(최대 +25%) | #치명 |
| 한 판 반응 200회 | 반응 중독 | 반응 발생 시 1% 확률로 룬 시계 0.5초 가속 | #템포 |
| 룬 3개로 클리어 | 미니멀리스트 | 빈 칸 1개당 오브 피해 +3% | #처치 |
| 펫 20종 수집 | 동물원장 | 펫 액티브 쿨다운 −10% | #소환 |
| 그림자 추월 100회 | 앞서 가는 자 | 추월 순간 0.5초 시간 정지 | #그림자 |
| 부활 없이 챕터 클리어 | 한 번뿐인 시간 | 첫 사망을 1회 무효화(판당) | — |
| 화상으로 1만 처치 | 방화범 | 화상 지속 +1초 | #화상 |
| 결투장 패링 300회 | 초침 검객 | 본 게임에서 피격 직전 회피 시 룬 1회 발동 | #템포 |
| 전술 퍼즐 100개 | 시계판 군사 | 판 시작 시 룬 1개를 원하는 칸에 미리 배치 | #정오 |

### 4.3 층 ③ 숨은 시너지 · 히든 각성
- 특정 조합 동시 장착 시 발동하는 **숨은 시너지 12종 이상**(시즌마다 추가), 유니크 이상 아이템의 **히든 각성** — [09 문서](09-hidden-codex.md).

### 4.4 수직 성장 제한 (숫자 인플레 억제)
| 장치 | 내용 |
|---|---|
| 훈련 효율 체감 | 훈련 레벨이 챕터 권장치를 넘으면 효율 50% |
| 전투력 표시 | 단일 숫자 대신 **"전투력 + 빌드 태그"** 표시 (예: 18,420 · 화상/정오/그림자) |
| 콘텐츠 설계 | 보스마다 **기믹**(원소 저항 교체, 반사 방패, 분열)을 두어 한 빌드로 모든 콘텐츠를 밀 수 없게 |
| 보상 | 새 조합·새 반응 **첫 발견 보상**을 큰 편으로 → 다양한 시도 유도 |

## 5. 스토리 — "끝나지 않는 시간선" ★

### 5.1 구조
| 단위 | 분량 | 내용 |
|---|---|---|
| **시대(Era)** | 5챕터 = 50스테이지 | 하나의 완결된 이야기(기승전결 + 반전). 끝은 항상 다음 시대로 넘어가는 **클리프행어** |
| 챕터 | 10스테이지 | 한 개의 사건. 챕터 보스 = 사건의 원인 |
| 스테이지 | 대사 **최대 6줄** | 전투 전 2줄 + 전투 후 2~4줄. 언제든 스킵 가능, 스킵해도 "이전 줄거리" 3줄 요약 제공 |

- **영원히 이어지는 이유(설정)**: 기사는 부서진 시간을 되감으며 싸운다. 한 시대를 구하면 시간선이 다른 시대로 튕겨 나간다 → 매 시대마다 **배경·동료·적 세력이 완전히 바뀐다**(고대 제국 → 증기 도시 → 꿈의 바다 → 별의 도서관 → …).
- **지루하지 않게 만드는 규칙**
  1. 시대마다 **장르 톤을 바꾼다**(모험 → 미스터리 → 코미디 → 비극 → 우주 오페라).
  2. 영구 주역은 3명으로 고정: **기사**(말 없는 주인공), **시계공 노라**(수다스러운 안내자, 개그 담당), **그림자**(과거의 나, 시대마다 조금씩 말수가 늘어나며 정체가 드러남 = 장기 미스터리).
  3. 한 시대에 **떡밥 1개 회수 + 새 떡밥 1개**. 전체 미스터리(“누가 시간을 부쉈나”)는 천천히 조각을 공개.
  4. 스토리 선택지(시대당 2회): 결과가 다음 시대의 **동료·보너스 규칙**에 반영(예: 제국의 기술자를 구하면 다음 시대 오브 합성 비용 −10%).
- **업데이트 주기**: 시즌(28일)마다 1챕터 추가, 5시즌 = 1시대. 콘텐츠 공백 대비 "외전"(요일 던전과 연결된 짧은 에피소드).

### 5.2 시대 로드맵 (초안)
| 시대 | 제목 | 톤 | 핵심 떡밥 |
|---|---|---|---|
| 1 | 부서진 시계 광장 | 모험 | 시계탑 심장이 왜 멈췄나 / 그림자는 누구인가 |
| 2 | 태엽 제국의 황혼 | 정치 미스터리 | 제국이 시간을 "팔았다"는 소문 |
| 3 | 증기와 거품의 도시 | 코미디 | 노라의 과거(시계공 길드 추방) |
| 4 | 꿈의 바다 | 몽환·비극 | 그림자가 처음으로 말을 건다 |
| 5 | 별의 도서관 | 우주 오페라 | 시간을 부순 자의 첫 등장 |
| 6~ | 매 시대 새 세계관 | 교차 | 전체 미스터리 단계적 공개, 최종장은 두지 않고 "다음 시간선"으로 계속 |

### 5.3 연출 (저비용)
- 대사창 + 캐릭터 흉상(생성 아트 1장 + 표정 3종 변형), 배경은 해당 챕터 로비 배경 재사용.
- 시대 전환 시에만 30초 컷신(정지 일러스트 4컷 + 패닝 + 자막).
- 대사 데이터는 `assets/story/era_XX.json` 에 작성(현지화 키 분리). Claude Code 가 시즌마다 추가 작성.
