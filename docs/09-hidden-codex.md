# 09. 히든 코덱스 — 히든 아이템 12종 · 히든 레시피 · 숨은 시너지

> ⚠️ **스포일러 · 내부 전용 문서.** 저장소를 공개로 전환하거나 외부 공유 시 이 파일을 제외한다.
> 앱에는 평문으로 넣지 않는다(해시·암호화 저장, [05 문서 §12](05-security-compliance.md)).

---

## 1. 히든 공통 규칙

| 항목 | 규칙 |
|---|---|
| 획득 | **유니크 이상** 원본 아이템 + **각성 조건 달성**(매우 어려움) + **히든 합성 레시피** → 100% 고정 결과 |
| 소환 | 불가 (확률형 상품이 아님 → 결과가 결정적이므로 확률 공시 대상 아님. 단 "히든 등급이 존재하며 조건 달성으로만 얻는다"는 사실은 공개) |
| 기본 능력치 | 유니크 + (레전드 − 유니크) × 0.7 = **×2.93** |
| 특수 능력 | 판 내부에서 **조건부로 누적 성장** — 숙련자가 쓰면 레전드의 3~6배, 조건을 못 맞추면 유니크 수준 |
| 조건 진행 표시 | 조건을 처음 **우연히 10% 달성**하기 전까지는 완전히 숨김 → 이후 원본 아이템 툴팁에 "???의 떨림 (12%)" 게이지만 표시 |
| 각성 방식 | 조건 100% → 원본 아이템에 **"깨어나는 각인"** 생성 → 합성 화면 ??? 슬롯에 원본 + 재료를 넣으면 히든 탄생 |
| 성장 | 히든은 중복이 없으므로 **시간 결정**(레전드 3개 합성 부산물)으로 ★ 상승 |
| 제한 | 같은 히든 1개만 존재 가능. 히든은 동시에 **최대 2개**까지 장착(오브 1 + 펫 1, 또는 히든 룬 1 포함) |

**조건 난이도 목표**: 일반 유저 기준 최소 1~3개월 플레이 + 빌드 연구가 필요한 수준. 결제로 단축 불가(소환·패키지와 무관한 조건만 사용).

## 2. 히든 오브 (5)

| # | 히든 이름 | 원본 | 각성 조건 | 히든 레시피 (??? 슬롯) | 특수 능력 (조건부 성장) |
|---|---|---|---|---|---|
| H01 | **영겁의 추** | O44 시계추 오브 (U) | 한 판에서 원소 반응 **400회** 달성 후 클리어 | 원본 + 레전드 오브 1 + 크로노 조각 3,000 | 판 내 원소 반응 1회마다 추의 피해 +1% **(상한 없음)**. 반응 빌드 숙련자는 후반 +400% 이상 |
| H02 | **역류하는 모래시계** | O40 모래 왕의 시계 (U) | HP 10% 이하 상태에서 보스 처치 **누적 7회** | 원본 + 모래 계열 레어 오브 3 | 잃은 HP 1%당 피해 +3%, HP 10% 이하에서는 장판이 시간을 **되감아** 적을 3초 전 위치로 끌고 감 |
| H03 | **이름 없는 공허** | O43 사건의 지평선 (U) | 룬을 **4개 이하**만 배치한 상태로 챕터 8 보스 클리어 | 원본 + 노멀 룬 12종 각 1개(비움의 의식) | 룬 시계의 **빈 칸 1개당** 피해 +30% · 흡입 반경 +8%. 룬을 버릴수록 강해지는 역발상 빌드 |
| H04 | **거울 속 태양** | O42 무한 거울 (U) | 그림자 레이스 **"완벽한 시간선" 30회** | 원본 + 태양 계열 레어 오브 2 + 달 계열 레어 오브 2 | 그림자와의 거리가 가까울수록 광선 피해 최대 ×4. 그림자에서도 광선이 발사됨 |
| H05 | **제13시** | O47 정오의 태양 헬리오스 (L) | 유일룬 보유 + 무한의 탑 **150층** 돌파 | 원본 + 시간 결정 5 | 룬 시계에 **13번째 칸(중앙)** 추가. 중앙 칸은 바늘이 12시와 6시를 지날 때 2번 발동하며, 중앙 룬은 모든 인접 반응의 "다음 칸"으로 취급 |

## 3. 히든 룬 (3)

| # | 히든 이름 | 원본 | 각성 조건 | 히든 레시피 | 특수 능력 |
|---|---|---|---|---|---|
| H06 | **공명 결정** | 유니크 이상 등급의 아무 룬 | 12칸을 **모두 같은 원소**로 채운 상태로 챕터 클리어 | 원본 + 같은 원소 레어 룬 6 | 같은 원소끼리도 반응 발생. 같은 원소가 연속된 칸 수 n에 대해 연쇄 배율 ×(1 + 0.15n²) — 단일 원소 올인 빌드가 성립 |
| H07 | **잊힌 초침** | 유니크 이상 뇌 룬 | 한 판에서 룬 **레벨 합계 60** 달성 | 원본 + 번개 초침(L) | 발동할 때마다 **직전에 발동한 룬 효과를 한 번 더 복제**. 복제가 반응을 일으키면 복제의 복제(최대 3단) |
| H08 | **역시계** | 유니크 이상 암 룬 | 액티브 A04 '시계 역행'을 한 판에 **20회** 사용 후 클리어 | 원본 + 시간 도둑(U) + 크로노 조각 2,000 | 바늘이 반 바퀴마다 방향 전환 — 모든 인접 반응이 **양방향**으로 적용. 방향 전환 순간 짧은 시간 정지 |

## 5. 숨은 시너지 (조합 발견형, 히든 도감)

특정 조합을 **동시에 장착**하면 발동하는 비공개 효과. 발견하면 "숨은 시너지 도감"에 기록되고 이후 툴팁에 공개된다.

| # | 조합 | 시너지 이름 | 효과 |
|---|---|---|---|
| X01 | 달 여우 루나 + 일식 오브 | 월식 사냥 | 오브 전환 순간 분신 2체 즉시 소환 |
| X02 | 크로노 부엉이 + 유일룬 정오의 왕관 | 두 번 울리는 정오 | 정오의 왕관 발동이 바퀴당 2회 |
| X03 | 번개 다람쥐 + 천공의 뇌정 | 도토리 뇌운 | 번개 튕김마다 도토리 폭발 |
| X04 | 액티브 A01 시간 정지 + 유일룬 윤초 | 정지된 세계 | 시간 정지 지속 +2초, 윤초가 매 바퀴 2초로 |
| X05 | 서리 토끼 + 서리불 쌍구 | 김 서린 발자국 | 서리 장판 위 증기 폭발 피해 ×2 |
| X06 | 패시브 S07 + 달그림자 셀레네 | 그림자 동무 | 그림자 위성이 추월 시 폭발 |
| X07 | 태엽 원숭이 + 역설의 룬 | 미래 원숭이 | 원숭이 액티브가 미보유 룬도 발동 |
| X08 | 액티브 A16 시간 저당 + 역류하는 모래시계 | 빚진 시간 | 저당 HP 소모가 피해 증가로 즉시 환산(×1.5) |
| X09 | 폭풍 그리폰 + 폭풍의 눈 | 눈 속의 날개 | 그리폰 폭격이 번개장 안에서 2배 |
| X10 | 유리 사슴 + 무한 거울 | 크리스털 미로 | 결정 벽이 광선을 반사 |
| X11 | 태양사자 솔라 + 정오의 태양 헬리오스 | 한낮의 왕 | 12시 발동 시 포효 자동 발동(쿨 무시, 30초 1회) |
| X12 | 구리 거북 + 성역(룬) + A13 성역 | 삼중 성벽 | 성역 계열 효과 중첩 시 반사 피해 추가 |

- 조합 수를 **시즌마다 3~5개씩 추가** → 커뮤니티 발견 경쟁(인스타·커뮤니티 "숨은 시너지 찾기" 이벤트 소재).

## 6. 밸런스 가드레일

| 위험 | 대응 |
|---|---|
| 히든 + 유일 동시 사용으로 폭주 | 무한의 탑·거울의 시련에는 **점수 보정**(동일 빌드 연속 사용 시 보상 감소는 하지 않고, 리더보드만 "무제한 / 표준" 두 부문 분리) |
| 조건 파밍을 위한 반복 노동화 | 조건은 "한 판 안에서 달성"형 위주, 누적형은 일반 플레이로 자연스럽게 쌓이는 항목만 |
| 데이터마이닝 유출 | 레시피·조건은 해시 매칭(§05-12), 효과 코드는 서버 없이도 난독화된 효과 타입 ID로 분리 |
| 결제 연관 논란 | 히든 조건·레시피에 **유료 전용 재화·상품이 필요 없음**을 약관과 공지에 명시 |
