# CHRONO KNIGHT — 룬 시계의 기사 (가제)

> **한 손가락, 5분 한 판, 시계 하나로 완성하는 나만의 빌드.**
> 단일 기사 육성 + 로그라이트 서바이벌 + "룬 시계(Rune Clock)" 빌드 퍼즐 + "그림자 라이벌(나 자신과의 경쟁)"

Google Play(Android) 출시를 목표로 하는 모바일 게임 기획 문서 저장소입니다.
모든 개발은 **Claude Code로 100% 진행**하는 것을 전제로, 에디터(GUI) 의존 없이
텍스트/코드만으로 빌드·테스트·배포가 가능한 구조로 설계했습니다.

## 한 줄 요약

| 항목 | 내용 |
|---|---|
| 장르 | 캐주얼 액션 로그라이트 (서바이버류) + 방치형 성장 |
| 플랫폼 | Android (Google Play), 세로 화면, 한 손 조작 |
| 핵심 신규 개념 | ① **룬 시계**: 12칸 시계판에 스킬을 배치 → 시곗바늘이 지나갈 때 발동, 인접 배치로 원소 연쇄 ② **그림자 라이벌**: 내 최고 기록의 '그림자'가 같은 판에서 경쟁 / 주간 '거울의 시련'에서 내 빌드의 복제와 결투 |
| 육성 | 단일 캐릭터(기사) — 레벨, 훈련, 장비 6부위, 룬 숙련 |
| 수익 모델 | 장비 소환(가벼운 갓챠, 천장·마일리지·확률 공개) + 월정액 + 시즌패스 + 보상형 광고 (강제 광고 없음) |
| 기술 | Kotlin + Jetpack Compose(UI) + 자체 경량 2D 엔진(SurfaceView), 순수 Kotlin 시뮬레이션 모듈 |
| 데이터 보관 | **Google Play 게임즈 서비스 저장된 게임(Saved Games)** — 구글 계정 연동 클라우드 저장, **서버 비용 0원** + 기기 로컬 암호화 저장 |
| 서버 | 출시 1단계: 서버 없음 (운영비 0원). 2단계(선택): Firebase 무료 티어 |

## 비용 판단 결과 (요청 사항 반영)

- **구글 계정 연동 저장은 무료로 가능**합니다. Google Play 게임즈 서비스(PGS)의 *저장된 게임* 기능은
  사용자 본인의 Google Drive 숨김 앱 영역에 저장되므로 개발사 서버/스토리지 비용이 발생하지 않습니다.
- 따라서 **"구글 계정 클라우드 저장 + 기기 로컬 저장" 병행** 방식을 채택합니다.
  (PGS 로그인이 불가능한 환경에서도 로컬 저장만으로 정상 플레이)
- 필요 비용은 Google Play 개발자 등록비(1회 $25)뿐입니다.
